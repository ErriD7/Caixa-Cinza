# Introdução

Este repositório documenta a execução de testes funcionais de **caixa cinza** sobre a API de autenticação do **Supabase** (GoTrue), utilizando o **Postman Desktop**. No teste de caixa cinza, o testador conhece parcialmente a estrutura interna do sistema: aqui, são conhecidos o endpoint, os headers, o formato do body JSON e os códigos de resposta HTTP esperados, mas não o código-fonte do serviço.

**Ferramentas utilizadas:**

| Ferramenta | Finalidade |
|---|---|
| Supabase | Serviço de autenticação (e-mail e senha) |
| Postman Desktop | Montagem e execução das requisições HTTP |
| GitHub | Versionamento e entrega da documentação |

**Estrutura do repositório:**

```
/README.md
/postman/    -> collection e environment exportados do Postman
/prints/     -> evidências (capturas de tela)
/planilha/   -> planilha de registro dos testes
```



# Objetivo da Atividade

Compreender e aplicar testes de caixa cinza em APIs de autenticação, configurando um ambiente no Supabase, criando usuários de teste, executando requisições HTTP no Postman, validando as respostas (status, JSON, mensagens de erro e access token) e documentando tecnicamente todo o processo.
